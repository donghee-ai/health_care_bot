# 웹앱 디자인 시안 — CALM (후보)

같은 데이터(스쿼트 카운트 · MoveNet 자세 추정 · UNO Q 상태 모니터링)를
서로 다른 제품처럼 보이게 만든 시안을 처음엔 4종 만들었다.
검토 결과 **CALM 하나만 후보로 남기고 나머지 셋은 삭제**했다.

> **상태: 후보 (2026-07-21).** CALM은 확정된 프로덕션 UI가 아니라 아직
> 검토 중인 후보다. 이전 웹앱은 `backup/web_2026-07-20_pre_redesign/`에,
> 삭제된 시안 3종은 §2의 백업 경로에 그대로 있다.
>
> 이 문서는 **웹 프론트엔드 작업 기록**이다. 추론 루프(MoveNet, 카운터,
> PTZ 제어, `src/*.py`)는 이번 작업에서 전혀 건드리지 않았다.
> 서버 API 계약(`/stats.json`, `/api/*`)도 그대로다.

## 1. 보는 방법

```
/app                     CALM (후보)
/app?role=operator       조작 권한까지 (세션 버튼 · PTZ 패드)
/app?demo=1              로봇 없이 둘러보기 (합성 데이터)
```

- 삭제된 시안 주소(`?ui=instrument` 등)는 자동으로 CALM으로 폴백한다.
- 시안 전환 구조(레지스트리 · 피커 · `useVersion`)는 일부러 남겨뒀다 —
  CALM이 "확정 UI"가 아니라 "후보"임을 구조로 드러내고, 후보를 다시
  늘리거나 교체할 때 그대로 쓰기 위함이다. 화면 우상단 **`시안 정보`**
  버튼(또는 키 `v`)으로 현재 후보를 확인할 수 있다.

### 데모 모드

로봇 없이 노트북에서 시안을 검토·발표 리허설할 수 있다. `?demo=1`을
붙이거나, `/stats.json`에 한 번도 못 붙으면 자동으로 켜진다.
**실제 stats가 한 번이라도 도착하면 절대 켜지지 않으므로** 디바이스
동작에는 영향이 없다. 데모일 때는 화면에 항상 표식이 뜬다
(`DEMO` / `견본` / `둘러보기`).

합성 데이터는 실측 범위에 맞췄다 — FPS 10.8, CPU 83%, 스쿼트 주기 3.2초.
카메라 자리에는 MoveNet과 같은 골격을 무릎 각도에 맞춰 그린다.

## 2. CALM — 남은 후보

Gentler Streak이 애플 디자인 어워드를 받은 이유가 "못 채운 날을 실패로
만들지 않는 설계"였다는 점을 가져왔다.

| | CALM |
|---|---|
| 성격 | 숨쉬는 코치 |
| 계열 | Gentler Streak · Apple Fitness · Things 3 |
| 바탕 | `#eef2ef` |
| 강조 | 딥그린 `#0f4c3a` · 옐로 `#f2b705` |
| 디스플레이 서체 | Gabarito |
| 모서리 | 14–24px |
| 그림자 | 아주 얕게 |
| 답하는 질문 | "괜찮게 하고 있나" |

- 값이 아니라 **상태**를 먼저 말한다. 장치 수치를 "로봇이 편안하게
  돌아가고 있어요"로 번역해 앞에 두고, 정확한 숫자는 아래 작게 둔다.
- "17회 남았어요"이지 "17회 부족"이 아니다.
- 진척을 애플 피트니스식 **링**으로 그린다. 큰 모서리와 얕은 그림자로
  촉감을 만든다 — 삭제된 세 시안이 전부 각져 있던 것과 대비된다.

### 삭제된 시안 3종 (참고)

CALM을 고르면서 아래 셋은 삭제했다. 되살리려면 백업에서 해당 폴더와
`fonts.css` 항목·폰트 파일을 가져오면 된다
(`backup/web_2026-07-20_pre_redesign/src/versions/`,
`.../public/fonts/`).

| | INSTRUMENT | ALMANAC | STADIUM |
|---|---|---|---|
| 성격 | 정밀 계측기 | 기록하는 종이 | 중계 스코어보드 |
| 계열 | Linear · Vercel · 글래스콕핏 | Oura · 편집 조판 | Strava · Nike · 방송 그래픽 |
| 바탕 | `#0a0b0d` | `#f4f0e6` | `#0b0b0b` |
| 강조 | 라임 `#c8f751` | 벽돌 `#8a3b2c` | 주황 `#ff3b00` |
| 서체 | Spline Sans Mono | Newsreader | Archivo (wght+wdth) |
| 답하는 질문 | "장비가 지금 어떤가" | "오늘 무엇을 했나" | "몇 개 남았나" |

- **INSTRUMENT** — 장식을 걷어내고 수치·단위·상태만 남긴 계기판. 헤어라인
  격자, 깊이 막대의 인정 임계선 눈금, 사람 위치 눈금으로 PTZ 이유 설명.
- **ALMANAC** — 대시보드가 아니라 오늘 자 지면. 제호·2단 조판·그림 설명·
  계측표·판권란. 진척을 눈금자로 그리고 구획은 전부 괘선으로 나눔.
- **STADIUM** — 2~3미터 밖에서 0.3초 안에 읽히는가만 기준. 횟수 숫자
  최대 190px, Archivo 폭 축(wdth 78)으로 좁게 세움, 방송 로워서드 3분할.

## 3. 리서치에서 뒤집힌 것들

Playwright로 22개 사이트(WHOOP·Oura·Strava·Linear·Vercel·Eight Sleep·
Nike·Arc 등)의 계산된 스타일을 긁어 팔레트와 서체를 실측했고,
서체·모션·색 체계는 별도로 조사했다. 그 결과 **초기 선택 몇 개가
근거를 잃어서 바꿨다.**

### 서체를 바꾼 이유

| 처음 골랐던 것 | 바꾼 것 | 이유 |
|---|---|---|
| Instrument Serif | **Newsreader** | Instrument Serif는 Space Grotesk·Geist와 함께 2026년 기준 "AI가 만든 티"로 지목되는 조합. Newsreader는 숫자가 기본으로 tabular + lining이라 표에 그대로 쓸 수 있다 |
| Fraunces (후보) | 탈락 | **`tnum` 기능이 아예 없다.** 실시간으로 바뀌는 숫자를 다루는 앱에서 자릿수가 흔들리는 서체는 애초에 후보가 아니다 |
| Anton | **Archivo** | Anton은 단일 굵기. Archivo는 wght+wdth 2축이라 압축 디스플레이와 표제를 파일 하나로 내고, 숫자 기능이 가장 충실하다 |
| Outfit | **Gabarito** | Outfit은 "AI 기본값" 계열로 닳았다 |
| JetBrains Mono | **Spline Sans Mono** | "코드 에디터 폰트"라는 기성 인상이 덜하고, UI용으로 설계돼 셀 폭이 좁다 |

한글은 (삭제된 시안 포함) 전부 **Pretendard**였다. 한국어 UI에서 사실상
표준이고, 여기서 개성을 내려다 가독성을 잃는 건 손해다. 개성은 라틴/숫자
디스플레이 서체 쪽에서 만든다. CALM은 Gabarito를 쓴다.

> 위 표는 4종을 만들 때의 서체 결정 근거다. 삭제 후 실제로 남은 건
> Pretendard + Gabarito뿐이고, Spline Sans Mono / Newsreader / Archivo는
> 백업에만 있다. 결정의 맥락으로 남겨둔다.

### 고친 실제 결함

- **INSTRUMENT 팔레트 대비 미달** — `--ink-3`가 라벨 텍스트 색으로
  18곳에 쓰이는데 대비가 읽기 한계 아래였다. 그리고 `--crit`(위험)이
  `--warn`(주의)보다 어두워서 **가장 급한 상태가 가장 안 읽혔다.**
  둘 다 밝은 쪽으로 올렸다.
- **`ch` 단위 함정** — Pretendard·Inter는 `1ch`가 tabular 자폭보다
  약 3% 좁다. `width: 5ch`로 숫자 칸을 잡으면 조용히 잘린다. 안 썼다.
- **`font-feature-settings` 우선순위** — 이게 `font-variant-numeric`보다
  우선해서, 어딘가에서 한 줄 선언되면 tabular이 무력화된다.
  숫자 요소에 방어적으로 `font-feature-settings: normal`을 걸었다.
- **커닝이 tabular을 깨는 경우** — 일부 서체는 고정폭 숫자에까지
  커닝 페어를 걸어둬서 `"11111"`과 `"00000"`의 폭이 달라진다.
  `font-kerning: none`을 같이 건다.
- **한글 줄바꿈** — 한글 음절은 유니코드상 표의문자로 분류돼, 기본값이면
  브라우저가 아무 음절 사이에서나 줄을 끊는다("한국어를" → "한국/어를").
  한국어는 어절 사이를 띄우므로 이건 그냥 틀린 동작이다.
  `word-break: keep-all`을 전역으로 걸었다.
- **본문 크기** — 한국 정부 디자인 시스템(KRDS) 기준 본문 17px / 행간 150%.
  한글은 같은 판독성에 라틴보다 큰 광학 크기가 필요한데, 한국어 UI에서
  가장 흔한 실수가 행간이 아니라 너무 작게 쓰는 것이다.

### 가변 축을 직접 잡았다

굵기를 400/600/700 같은 토큰 값으로 쓰면 "기본값 그대로"로 읽힌다.
가변 폰트에서만 낼 수 있는 값을 쓴다 — `wght 340`, `390`, `540`,
`580`, `620`, `wdth 78`, `opsz 60/72`. 작은 라벨(12px 이하)에는
**양수** 자간, 큰 숫자에는 음수 자간. 큰 글자 기준 음수 자간을 라벨까지
일괄 적용하는 게 흔한 실수다.

## 4. 폰트 로딩

로봇은 LAN 전용이라 구글 폰트 CDN에 못 나간다. CDN을 쓰면 시연장에서
폰트만 통째로 안 뜨는 사고가 난다. **전부 self-host.**

Pretendard 원본은 2.0MB다(한글 음절 11,172자 전부). "QR 스캔 후 3초"
목표와 정면으로 부딪혀서 `scripts/subset_pretendard.py`로 쪼갰다.

- **`kr-core.woff2`** — 소스에 실제로 등장하는 글자만 모은 우선 조각.
  화면에 뜨는 한글은 거의 전부 여기서 해결된다.
- **`kr-NN.woff2`** — 나머지 음절. 문구를 바꿨을 때를 위한 안전망.
  모든 글자가 어딘가에는 있으므로 **두부(□)가 원천적으로 불가능하다.**
- 시안별 디스플레이 서체는 `@font-face`가 실제로 쓰일 때만 받으므로,
  지금 보는 시안의 폰트만 네트워크를 탄다.

폰트를 추가하거나 한국어 문구를 크게 바꿨으면 다시 돌린다:

```bash
cd web && python scripts/subset_pretendard.py
```

원본은 `web/fonts-src/`에 둔다 (`public/`에 두면 dist에 2MB가 그대로 실린다).

### 디스크와 전송량은 다르다

`public/fonts/`는 조각 46개를 합쳐 **디스크에서 4.3MB**다. 하지만
브라우저가 실제로 **전송받는 건 226~346KB**뿐이다 — 나머지는 문구를
바꿨을 때를 위한 안전망이라 평소엔 아무도 받아가지 않는다.

`dist/`는 `.gitignore`돼 있지만 `public/fonts/`는 아니라서, 커밋하면
레포에 4.3MB가 들어간다. 판단이 필요한 지점이다:

- **그대로 커밋** — clone 후 `npm run build`만으로 끝난다(파이썬 불필요).
  가장 안전하지만 레포가 무거워진다.
- **`public/fonts/pretendard/`를 무시** — 레포는 가볍지만 빌드 전에
  `python scripts/subset_pretendard.py`를 반드시 돌려야 하고,
  `fonts-src/`(2MB)는 여전히 커밋해야 한다.

아직 정하지 않았다.

## 5. 구조

```
src/
  App.tsx                시안 라우팅 + 단축키
  api.ts, types.ts       서버 계약 (변경 없음)
  base.css               시안이 공유하는 최소한의 바닥
  fonts.css              @font-face 선언 (Pretendard + Gabarito)
  pretendard.css         (생성됨) unicode-range 조각
  hooks/                 동작만 — 생김새는 시안이 소유
    useStats             폴링 + 연결 상태 + 데모 폴백
    useMjpeg             스트림 재연결 · 전체화면
    useRepPulse          "1회 인정" 순간 감지
    usePressRepeat       PTZ 길게 누르기 반복
    useVersion           시안 선택 (URL > 저장값 > 기본)
  components/DemoPose    데모용 합성 골격
  shell/VersionPicker    시안 전환 시트 (후보 목록)
  versions/
    registry.ts          시안 메타 + 공통 props 타입
    calm/                남은 후보 1종
```

**시안끼리 스타일을 공유하지 않는 구조를 유지한다.** 각 시안은 자기
`.tsx` + `.css`를 통째로 소유하고 lazy로 나뉘어, 보는 시안의 CSS만
로딩된다 — 시안이 여럿일 때 서로의 CSS가 한꺼번에 들어와 덮어쓰는 사고를
막던 구조다. 지금은 후보가 하나뿐이지만, 후보를 다시 늘릴 때 그대로
쓰려고 남겨뒀다.

공유하는 건 **데이터와 동작**뿐이다 — 훅은 값을 계산하고 상태를 관리할
뿐 마크업을 만들지 않는다. (`useSeries`는 스파크라인을 쓰던 INSTRUMENT·
STADIUM과 함께 삭제됐다.)

## 6. 검증한 것

`npm run build` 통과, 그리고 Playwright로 CALM × 모바일(402px)/
데스크톱(1440px) + 삭제된 시안 URL 폴백을 자동 확인:

- CALM이 **자기 디스플레이 서체(Gabarito)를 실제로 로드**하는지 (폴백 아님)
- 큰 숫자에 **tabular-nums가 걸려 있는지**
- **가로 스크롤이 생기지 않는지**
- 삭제된 시안 주소(`?ui=instrument` 등)가 **CALM으로 폴백**하는지,
  삭제된 시안 루트(`.ins`/`.alm`/`.std`)가 **남아있지 않은지**
- 피커 후보가 **1개**인지, 시트가 열리는지
- 콘솔 에러 없음

### 아직 확인 못 한 것

- **실기에서 안 돌려봤다.** 데모 데이터와 빌드까지만 확인했고,
  UNO Q에 올려 실제 MJPEG 스트림·실제 PTZ 조작으로 검증하는 건 남았다.
- 실제 스트림이 들어왔을 때의 프레임 밀도, 조작 지연, 배터리·발열 영향은
  디바이스에서 봐야 한다.
- 아이폰 사파리 실기 확인이 남았다.

## 7. 되돌리기

이전 웹앱은 통째로 백업돼 있다:

```
health_care_bot/backup/web_2026-07-20_pre_redesign/
```

`src/`, `public/`, `dist/`, 설정 파일까지 전부 포함. 되돌리려면
`web/`의 `src`·`public`을 이걸로 덮고 `npm run build` 하면 된다.
