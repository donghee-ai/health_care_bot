# 2026-07-11 — 장비 상태 배치 반복 조정 + CPU 온도 필드 추가

## 시점

2026-07-11

## 사건

더보기 화면의 "장비 상태"(연결상태/FPS/추론루프/dropped frames/PTZ
serial/메모리/모델) 정보 배치를 사용자 피드백에 따라 여러 번 조정했고,
그 과정에서 백엔드에 CPU 온도 필드를 새로 추가했다. 최종 상태:

1. **더보기 화면** — "장비 상태"는 원래대로 탭-진입 메뉴 항목 하나로 복귀.
   전체 필드(연결상태/FPS/추론루프(지연)/dropped frames/PTZ serial/메모리/
   **CPU 온도**(신규)/모델)를 그대로 보여준다. "카메라 성능"이라는 별도
   항목으로 쪼갰던 중간 시도는 폐기.
2. **카메라 제어(운영자) 화면** — 한때 장비 상태 전체를 여기로 옮겼었으나
   최종적으로 제거 — PTZ 패드까지만 남는다.
3. **라이브 화면** — FPS/지연(ms)/CPU 온도/RAM 4개를 작은 카드로
   추가했지만 **데스크톱(≥900px)에서만** 보이고 **모바일에서는 숨김**
   (`index.css` `.hcb-live__telemetry`). 모바일은 카메라 + 현재 운동 +
   피드백까지만 유지.

**백엔드 변경**: `src/main.py`에 `get_cpu_temp_c()` 추가 —
`/sys/class/thermal/thermal_zone0/temp`(millidegree C)를 읽어 `stats.json`의
`cpu_temp_c` 필드로 노출. Windows/온도 노드 없는 환경에서는 `None` →
프론트에서 `—`로 표시. `scripts/mock_serve.py`에도 더미값(52.3) 추가.

**프론트 리팩터**: `MoreScreen.tsx`와 `CameraControlScreen.tsx`가 거의
동일한 `Row`/`InfoRow` 컴포넌트를 각자 정의하고 있던 걸
`web/src/components/InfoRow.tsx` 하나로 통합.

## 배경

첫 요청("더보기 항목 하나로 바로 들어가게")을 잘못 해석해 인라인 요약
카드 + "카메라 성능" 분리로 구현했는데, 사용자의 실제 의도는 "장비 상태
전체를 그대로, 제어 탭 아래로"였다. 그렇게 옮긴 뒤 다시 "그냥 더보기로
옮겨줘"로 최종 정정 — 결과적으로 원래 위치(더보기, 탭-진입 패널)로
돌아왔지만, 그 과정에서 CPU 온도 필드가 새로 생겼고 라이브 화면
텔레메트리 카드(데스크톱 전용)가 추가로 붙었다.

## 결과

로컬 mock 백엔드 + Playwright로 모바일/데스크톱 각 화면 스크린샷 확인,
콘솔 에러 0건. adb로 `src/main.py` + `web/dist` 디바이스에 반영 완료
(중첩 디렉토리 함정 발생 → `docs/issues/2026-07-11_02_...md`로 별도 기록).
