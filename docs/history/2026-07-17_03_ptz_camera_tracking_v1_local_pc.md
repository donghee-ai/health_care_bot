# 2026-07-17 — PC 로컬 카메라 PTZ 추적 v1 확정 + 백업

## 시점

2026-07-17 (yaw/pitch 캘리브레이션·가동범위 측정
[2026-07-17_02](2026-07-17_02_yaw_pitch_range_of_motion_measured.md) 이어서)

## 사건

이 PC(개발 노트북)에서 웹캠 + MoveNet 포즈 + ST3215 서보를 직접 묶어 사람을
따라가는 PTZ 추적을 처음으로 실동작시켰다. MCU를 거치지 않고 PC가 USB-TTL
어댑터(COM9)로 서보를 직접 구동하는 구조(`scripts/st3215_bus.py` 재사용).
사용자가 동작 결과에 만족("굉장히 맘에 든다")해서 이 상태를
`scripts/ptz_camera_track_v1.py`로 백업(byte-identical)했다.

신규 스크립트: `scripts/ptz_camera_track.py` (작업본) / `..._v1.py` (동결본).

## 배경

- 실행 환경 함정: 이 PC엔 파이썬이 둘(아나콘다 base = cv2 없음 / Python 3.14 =
  cv2·numpy·pyserial·ai-edge-litert 전부 있음). **반드시 Python 3.14로 실행**
  (`py -3.14 ...` 또는 전체경로). `ai-edge-litert`는 이번에 이 PC에 신규 설치.
- 카메라가 2대(index 0=내장 웹캠, index 1=짐벌 카메라) → `--camera 1` 사용.
- 안전: 서보 명령은 항상 소프트리밋(yaw 90~270=중앙±90 / pitch 150~210=중앙±30,
  tick 2047 캘리브레이션 기준) 안으로 3중 클램프. 안전속도(569 tick/s) 고정.
  기본은 dry-run(서보 미구동), `--drive` 줘야 실제 구동.

## 결과 — v1 확정 기능

- **목표점 폴백 체인**: 양쪽 무릎 다 보이면 두 무릎 중점 → 한쪽만/없으면 엉덩이
  중심 → 그래도 없으면 몸통(어깨+엉덩이). "한쪽 다리로 카메라 쏠림" 문제 해결.
  (`--target knee|hip|weighted`, `--one-knee`)
- **시작 시 항상 중앙(180/180) 이동 후 추적 시작** (torque는 현재 위치로 안전하게
  켠 뒤 중앙으로, 이동거리 비례 대기).
- **속도**: 추적 속도 기본 1/2(`track_scale=0.5`), 양 무릎 다 보이면 추가로 1/2
  → 총 1/4로 더 천천히(`both_knee_scale=0.5`).
- **섹터 프레이밍**: 화면 좌우 1/6·중앙 4/6·1/6. 무릎(양쪽 다 보이면 두 무릎 모두)이
  중앙 4/6 밴드 안이면 정지, 밖으로 나가야 팬. 미리보기에 밴드 경계 청록 세로선 표시.
  (`--sector-side`, 기본 1/6)
- **획득→잠금(도리도리 제거)**: 목표가 존 안에 N프레임 연속 머물면 LOCK(정지),(컴퓨터 기준 현재 10)
  재개는 히스테리시스로 충분히 벗어날 때만. EMA 스무딩으로 키포인트 지터 완화.
  (`--lock-frames`, `--reengage`, `--smooth`)
- 성능: 이 PC에서 ~29 FPS(데스크톱 CPU). yaw 부호는 기본(+1)이 맞음.

실행:
`py -3.14 scripts/ptz_camera_track.py --port COM9 --camera 1 --drive`
